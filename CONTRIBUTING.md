# Contributing

Informal process, small project.

## Setup

```bash
git clone <this repo> ~/.dotfiles
cd ~/.dotfiles
./install.sh
```

## Before opening a PR

- run the tests: `see docs/development.md`
- keep the diff focused, one thing per PR
- commit messages in imperative mood

For anything bigger than a typo, open an issue first so we can
agree on the approach before you spend time on it.
